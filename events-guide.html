Arbortech – Updating the Events Calendar

Open days, trade shows and in-store demos: how to add, edit, hide and regionalise events. Events are self-maintaining — add them with the right dates and they appear and expire on their own.

On this page

1. Where events live 2. Adding an event 3. Choosing who sees it 4. Editing, hiding & expiry 5. The section itself 6. Confirm you can

1. Where events live

Events are not pages — each one is a structured entry under Content → Metaobjects → Event in the Shopify admin. The Events Calendar section on the site reads this list automatically: add an entry and it appears in date order; once an event's date (or end date) has passed, it drops off the site by itself. You never need to delete old events.

2. Adding an event

Open Content → Metaobjects → Event → Add entry and fill in:

FieldWhat it does
Title, Date and timeWhat shows on the event card
End dateFor multi-day events — the event stays visible until this day has passed
Image and BlurbThe card image and a sentence or two about the event
LocationThe venue exactly as you want it displayed, e.g. Timbecon, Balcatta
Link and Link labelOptional — where "View event" sends people (organiser's site, ticket page). Leave blank for no button
Show in countriesWhich storefronts display the event — see section 3
ActiveMaster switch — must be ticked for the event to show at all

Give every real event an image and a link

An event card with the generic banner image and no click-through looks unfinished. Each real event should have its own image and somewhere to send people — a registration page, the venue, or a news post.

3. Choosing who sees it

A local open day in Perth means nothing to a customer in Munich. Show in countries controls which storefronts display the event: pick one or more of AU, US, GB, DE, CA (matching the site's five markets) and only visitors on those countries' versions of the site will see it. Leave it empty to show the event everywhere — right for online events or international shows.

The UK is "GB"

The United Kingdom's country code is GB, not UK. The picker only offers valid codes, so you can't get it wrong — just don't go hunting for "UK" in the list.

If you run German-language events, the event text can be translated like any other content through Translate & Adapt (Manual §10).

4. Editing, hiding & expiry

  • To edit an event, open its entry under Content → Metaobjects → Event, change the fields and save — the site updates straight away.
  • To hide an event immediately (postponed, cancelled), untick Active. Nothing is deleted, and re-ticking brings it back.
  • Expiry is automatic — once the date (or end date) passes, the event disappears from the site on its own. Old entries can stay in the list as a record.

5. The section itself (heading, intro text)

The events entries are yours to manage as above. The Events Calendar section that displays them — its eyebrow, heading, intro text and calendar timezone — is a theme section (arb-events-calendar) edited in Online Store → Themes → Customize on the pages that carry it. Change the wording there if needed; the module handles ordering, timezones and the empty state ("no upcoming events") automatically. If you're unsure which page holds the section, ask us rather than hunting through templates.

6. Confirm you can

  • Add a test event dated next month and see it appear on the site.
  • Restrict it to one country and confirm it only shows on that storefront.
  • Untick Active and watch it disappear immediately; re-tick to restore.
  • Change its date to last week and confirm it drops off by itself — then delete the test entry.
